# K-meanas

**Датасет**: Задача 3. Распознавание цифр

## 1. Описание задачи и данные

В работе рассматривается набор данных из 500 изображений цифр от 0 до 9, представленных состояниями семи сегментов калькулятора.

Каждое наблюдение содержит правильную цифру и семь бинарных признаков, описывающих состояния сегментов. При считывании возможны ошибки: отдельные сегменты могут ошибочно включаться или выключаться.

Для кластеризации используются только признаки сегментов, без информации о правильной цифре.

## 2. Цель

Выполнить кластеризацию методом K-means изображений цифр, выбрать наилучшее количество кластеров, а также проанализировать полученные группы.

## 3. Результаты

Данные были разбиты на 10 кластеров. Полученное разбиение: 

- Кластер 0: преимущественно цифра 4 (73,0%).

- Кластер 1: преимущественно цифра 9 (62,0%).

- Кластер 2: преимущественно цифра 1 (84,6%).

- Кластер 3: преимущественно цифра 2 (87,2%).

- Кластер 4: преимущественно цифра 6 (75,4%).

- Кластер 5: преимущественно цифра 0 (86,5%).

- Кластер 6: преимущественно цифра 3 (59,6%).

- Кластер 7: преимущественно цифра 8 (70,2%).

- Кластер 8: преимущественно цифра 5 (83,7%).

- Кластер 9: преимущественно цифра 7 (71,7%).

Таким образом, каждому кластеру соответствует отдельная преобладающая цифра.
