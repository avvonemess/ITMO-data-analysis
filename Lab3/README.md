# DBSCAN

**Датасет**: Задача 3. Распознавание цифр

## 1. Описание задачи и данные

В работе рассматривается набор данных из 500 изображений цифр от 0 до 9, представленных состояниями семи сегментов калькулятора.

Каждое наблюдение содержит правильную цифру и семь бинарных признаков, описывающих состояния сегментов. При считывании возможны ошибки: отдельные сегменты могут ошибочно включаться или выключаться.

Для кластеризации используются только признаки сегментов, без информации о правильной цифре.

## 2. Цель

Выполнить кластеризацию изображений цифр методом DBSCAN, проанализировать полученные группы.

## 3. Результаты

Был проведен подбор параметров по следующей сетке:

- $\varepsilon = [10^{-6}, 1/7 + 10^{-6}, 2/7 + 10^{-6}]$
- $n = [2, 3, 5, 10, 15, 20, 30]$

Полученные результаты: 

- При $\varepsilon = 0.01$ формируется от 4 до 57 кластеров, состоящих из полностью совпадающих объектов. Количество шумовых объектов варьируется от 18 до 356 в зависимости от $n$.
- При $\varepsilon \approx 0.1429$ практически все объекты объединяются в один кластер. В зависимости от $n$ выделяется 1–2 шумовых объекта.
- При $\varepsilon \approx 0.2857$ все 500 объектов объединяются в один кластер без шума.

Таким образом, получить содержательное разделение изображений цифр на группы с помощью DBSCAN не удалось. Это связано с особенностями бинарных данных и склонностью DBSCAN выделять цепочки связанных объектов.  

Однако при $\varepsilon \approx 0.1429$ и $n = 20$ алгоритм выделил два шумовых объекта, которые при визуальном анализе оказались сильно искаженными изображениями цифр. Следовательно, в данном наборе данных DBSCAN оказался полезен для обнаружения аномалий.
