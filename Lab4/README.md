# Интерактивный дашборд

**Датасет**: Задача 3. Распознавание цифр  

**Ссылка на дашборд**: https://datalens.yandex/0eqnvjlzd0bqj?_share_link=public&tab=7Y

## 1. Задача

Построить интерактивный дашборд объединяющий результаты применения трёх методов кластеризации изображений цифр, представленных в виде семисегментного индикатора.

Набор данных содержит 500 объектов, каждый из которых описывается семью бинарными признаками — состояниями сегментов B–H. Для сравнения использованы три алгоритма:

- Иерархическая кластеризация;

- K-means;

- DBSCAN.

## 2. Цель

Исследовать структуру исходных данных, сравнить алгоритмы, оценить качество кластеризации и проанализировать полученные кластеры.

## 3. Таблицы

Для построения графиков были подготовлены следующие таблицы:

- digits. Исходные цифры и семь бинарных признаков B–H

- patterns. Уникальные комбинации сегментов и частота их появления для каждой цифры

- metrics. Таблица с итоговыми метриками по трем алгоритмам

- results. Итоговые метки всех алгоритмов кластеризации

- profiles. Средняя активация каждого сегмента B–H внутри кластеров

- hier_search. Таблица подбора параметров иерархической кластеризации

- k_means_search. Таблица подбора параметров k_means

- dbscan_search. Таблица подбора параметров DBSCAN
